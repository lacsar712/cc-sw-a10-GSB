# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程先把单子置为领取态并按当前设置快照超时秒数，处理期间持续心跳；心跳超过秒数仍无结论的单由回收线程自动退回待处理，并在回收流水留痕。页面轮询直到结论出现。

## 超时台

顶部导航「超时台」分三区：

1. **超时秒数设置**：校准员可改领取心跳超时秒数（1–3600），巡检员只读。保存后只约束**之后新进领取态**的单；已在领取态的单仍按领取时快照的秒数计时。
2. **领取态监视窗**：实时列出领取中的单、领取时间、最近心跳、快照秒数与剩余倒计时。
3. **回收流水**：每次超时回收一行，记录任务、触发秒数、原领取时间、回收时间与原因。

## 启动

```bash
docker compose up --build
```

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差；再提交普通样条，先待处理/领取中再出结论。
2. inspector 不能提交，也不能改超时秒数，但能进超时台看设置与回收流水。
3. **超时回收**：进超时台把秒数压到很小（如 2 秒）并保存；回总览勾选「拖住领取」提交一单。应见单子先「领取中」，约 2 秒后自动回到「待处理」，且回收流水出现新行；宽限结束后该单被重新领取并补出结论。
4. 改秒数不影响已在领取态的单（监视窗里的快照秒数不变），只对之后新领取的单生效。
